# CreatorAI Studio

A static, bilingual (English/Hindi UI) creator toolkit made with plain HTML, CSS and JavaScript. It does not use a paid API, backend, account system or subscription.

## Included tools
- YouTube Shorts prompt builder
- Title and description suggestions
- Hashtag suggestions
- Thumbnail text ideas
- English/Hindi interface toggle
- Copy buttons and responsive mobile layout

## Important limitation
The generators use local templates and simple JavaScript rules. They are **not a live generative AI model**, do not create video or images, and do not guarantee virality, views or earnings.

## Deploy on GitHub Pages
1. Sign in at https://github.com/ and create a new public repository, e.g. `creatorai-studio`.
2. Upload `index.html`, `style.css`, `script.js`, `about.html`, `privacy.html`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL usually looks like `https://YOUR-USERNAME.github.io/creatorai-studio/`.
